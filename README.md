# Islam Abu Saleem — Portfolio

A responsive implementation of the Stitch Neobrutalism portfolio, built with React, Vite, Material UI and custom CSS.

## Run locally

Use Node.js 20 or 22, open this folder in a terminal, and run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

Edit `src/content.js` to update project details and contact information. Verify the email from the mockup and fill in the phone number and full social profile URLs before publishing. Project previews reproduce the illustrative mockups from the design.

## Project structure

- `src/App.jsx` assembles the page.
- `src/sections/` contains the header, footer and each portfolio section. Project dialogs and contact feedback live with their own sections.
- `src/components/` contains shared interface components.
- `src/main.jsx` configures the Material UI theme and mounts the app.
- `src/portfolio.css` contains the responsive layout and Neobrutalism styling.
